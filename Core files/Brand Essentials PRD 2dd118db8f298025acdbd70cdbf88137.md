# Brand Essentials PRD

## Product Note: Brand Essentials

## What It Is

Brand Essentials is a **6-space diagnostic and planning system** that transforms brand uncertainty into executable strategy in 10-15 minutes.

It's not a tool. It's **the path** every brand takes before ShopOS can actually work for them.

One form → Six diagnostic spaces → Complete strategic foundation.

A clear path: Foundation → Intelligence → Presence → Optimization → Execution → Tracking

## The Problem

Brands arrive at ShopOS with:

- No clear starting point
- Broken fundamentals they don't know about
- No unified view of perception vs. reality
- Analysis paralysis about what to fix first

They don't need more tools. They need **clarity, priority, and structure**.

## The Solution

**Brand Essentials = The Default Onboarding**

Six spaces that answer six critical questions:

### 1. Foundation – AI Readiness Check

**Question:** *Can AI systems understand and crawl your site?*

**We check:** Schema + metadata completeness, Crawlability (robots.txt, sitemap), Content quality signals, Speed + mobile performance

**Output:**

- AI Readiness Score (0-100)
- Prioritized fix list (now / soon / nice-to-have)
- Technical blockers flagged

**Why:** If this is broken, everything else is wasted effort.

---

### 2. Intelligence – Deep Brand Research + Memory

**Question:** *What do AI and customers actually say about your brand?*

**We analyze:**

- AI mention frequency vs. competitors
- Reviews, Reddit, forums, social sentiment
- What people praise / complain about
- Perception gaps (what they say ≠ what you say)
- Competitive positioning

**Output:**

- AI visibility score
- Sentiment summary with examples
- Top 5 perception gaps
- Competitive position chart
- **Stored brand memory** → MCP context for all future workflows

**Why:** You can't fix what you don't see. This creates the single source of truth.

---

### 3. Agentic Store – Adaptive Storefronts

**Question:** *Can your store adapt to each visitor in real-time?*

**We enable:**

- Dynamic layouts per visitor intent
- Conversational commerce embedded
- AI-curated product collections per segment
- Contextual messaging (headlines, CTAs adapt)
- Smart search (understands intent, not keywords)

**How it works:**

1. Visitor lands → AI analyzes (source, behavior, device, location)
2. Store renders personalized version
3. Interaction → learning → next visit improves

**Output:**

- Agentic storefront deployed across platforms: Shopify (main site), WhatsApp Business, ChatGPT Store, Claude integration, Instagram Messenger
- Master dashboard for unified order management
- Platform-specific agent configurations
- Unified product catalog API

**Why:** Static stores are dead. Modern commerce is conversational and adaptive.

---

### 4. Optimization – GEO Recommendations

**Question:** *What exactly should we change on the site?*

**We generate:**

- Better product titles & descriptions
- Schema markup (ready to paste)
- Homepage + category copy
- FAQs optimized for AI
- Alt text for images
- Technical fixes with code

**Output:**

- Ready-to-deploy improvements list
- Before/after examples
- Code + copy included
- Clear implementation steps

**Why:** No theory. Just actionable fixes.

---

### 5. Execution – Priority Action Plan

**Question:** *What should I work on this week, this month, this quarter?*

**We provide:**

- Simple **30-60-90 day roadmap**
- Each task tagged:
    - **Impact** (High/Med/Low)
    - **Effort** (5min / 30min / 2hrs / Strategic)
    - **How** (DIY / ShopOS / Refine™)

**Example timeline:**

- **Week 1:** Fix robots.txt (5min, high impact) → Deploy top 5 product optimizations (30min)
- **Month 1:** Launch agentic WhatsApp store → Optimize product schema across catalog
- **Quarter 1:** Strategic repositioning of pricing message (Refine™)

**Why:** Brands fail from lack of prioritization, not lack of ideas.

---

### 6. Tracking – Success Metrics & Monitoring

**Question:** *Are these changes actually working?*

**We track:**

- AI readiness score (monthly)
- AI mention frequency
- Traffic sources & conversion
- Sentiment trends
- Agentic store performance by platform

**Output:**

- Simple dashboard (not overwhelming)
- Weekly summary emails
- Automated monthly re-scans
- Alerts if critical issues emerge (crawl blocks, broken schema)

**Why:** What gets tracked compounds. What doesn't gets forgotten.
